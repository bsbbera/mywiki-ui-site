# Cloud SDK

<p class="at-lead">
The Cloud SDK is a set of command-line tools for managing Google Cloud Platform resources. It includes gcloud for service management, gsutil for Cloud Storage, and bq for BigQuery — enabling developers and operators to automate infrastructure, run queries, and orchestrate deployments.
</p>

## Overview

The Cloud SDK provides authenticated access to all GCP APIs, supports configuration of multiple projects and accounts, and integrates with Cloud Shell for zero-install workflows. It is the backbone of CI/CD pipelines, infrastructure-as-code workflows with Terraform, and operational scripts that manage production environments at scale.
