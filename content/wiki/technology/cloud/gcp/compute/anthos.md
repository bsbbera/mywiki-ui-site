# Anthos

<p class="at-lead">
Anthos is Google's hybrid and multi-cloud application platform built on open-source technologies including Kubernetes, Istio, and Knative. It enables organisations to modernise existing applications, build new cloud-native services, and manage workloads consistently across on-premises data centres, Google Cloud, and other public clouds.
</p>

## Overview

Anthos provides a unified control plane for cluster management, service mesh traffic policy, and policy-driven configuration governance. Key components include Anthos GKE for Kubernetes clusters, Anthos Service Mesh for observability and security, and Anthos Config Management for GitOps-style configuration. It is designed for enterprises seeking cloud benefits without relinquishing on-premises infrastructure or committing to a single vendor.
