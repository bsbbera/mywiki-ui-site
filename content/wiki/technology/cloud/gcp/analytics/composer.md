# Cloud Composer

<p class="at-lead">
Cloud Composer is a fully managed Apache Airflow service on Google Cloud Platform. It enables data engineers to author, schedule, and monitor complex data pipelines across GCP, on-premises, and multi-cloud environments without managing Airflow infrastructure.
</p>

## Overview

Cloud Composer automates the provisioning, scaling, and patching of Airflow deployments with tight integration to BigQuery, Dataflow, Cloud Storage, and Kubernetes. It supports Python-based DAG authoring, rich UI monitoring, and identity-aware access control. For organisations already using Airflow, Composer eliminates operational overhead while providing enterprise-grade security and reliability.
