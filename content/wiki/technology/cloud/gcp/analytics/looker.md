# Looker

<p class="at-lead">
Looker is a modern business intelligence and data exploration platform that enables organisations to define metrics in a central semantic layer and empower users to self-serve analytics through dashboards, embedded visualisations, and natural language queries.
</p>

## Overview

Looker's key innovation is LookML, a modelling language that centralises metric definitions so every team derives the same numbers from the same source of truth. Integrated with BigQuery, Snowflake, Redshift, and other cloud warehouses, Looker supports embedded analytics, scheduled reports, and API-driven data experiences. Looker Studio (formerly Data Studio) provides a free, lightweight visualisation layer for creating interactive dashboards.
