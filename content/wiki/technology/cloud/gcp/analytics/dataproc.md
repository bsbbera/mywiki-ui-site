# Cloud Dataproc

<p class="at-lead">
Cloud Dataproc is a managed Spark and Hadoop service on Google Cloud Platform that enables fast, easy, and cost-effective big data processing. It supports ephemeral clusters that can be created, autoscaled, and deleted on demand, making it ideal for batch ETL, machine learning, and ad-hoc data science workloads.
</p>

## Overview

Dataproc integrates natively with Cloud Storage, BigQuery, and Pub/Sub, supporting PySpark, Spark SQL, Spark MLlib, and Hadoop ecosystem tools. It offers custom images, component gateways for Jupyter and Zeppelin, and serverless Spark through Dataproc Serverless for Batches. Its per-second billing and aggressive auto-scaling make it significantly more cost-efficient than persistent on-premises clusters.
