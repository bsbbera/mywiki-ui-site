# Classification

<p class="at-lead">
Classification is the supervised learning task of predicting a discrete category label for an input based on its features. From spam detection and medical diagnosis to image recognition and fraud prevention, classification is one of the most widely applied machine learning paradigms in industry.
</p>

## Overview

Classification algorithms learn decision boundaries from labelled training data. They range from simple baselines like Naive Bayes and logistic regression to powerful ensembles like random forests and gradient boosting, and to deep neural networks for unstructured data. Key considerations include class imbalance, calibration, interpretability, and the cost of false positives versus false negatives.
