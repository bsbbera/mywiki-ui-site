# Causality

<p class="at-lead">
Causality is the study of cause-and-effect relationships — determining whether changing one variable directly produces changes in another. It underpins A/B testing, policy evaluation, medical trials, and any decision where we need to predict the consequence of an action, not just describe associations.
</p>

## Overview

Causal inference frameworks include randomized controlled trials (the gold standard), observational methods like instrumental variables and difference-in-differences, and graphical models such as Pearl's do-calculus. Machine learning augments causal inference by handling high-dimensional confounders, but the fundamental challenge remains: separating true causal effects from spurious correlations created by hidden variables.
