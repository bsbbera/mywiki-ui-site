# Bayesian Inference

<p class="at-lead">
Bayesian Inference is a statistical paradigm that updates beliefs about parameters or hypotheses as new evidence is observed. It provides a principled framework for uncertainty quantification, regularisation, and sequential learning — powering modern machine learning from Gaussian processes to variational autoencoders.
</p>

## Overview

Bayes' theorem combines a prior distribution (beliefs before seeing data) with a likelihood (how probable the observed data is under different parameter values) to produce a posterior distribution (updated beliefs). This approach naturally handles small datasets, incorporates domain knowledge, and produces full predictive distributions rather than point estimates. In ML, Bayesian methods inform hyperparameter optimisation, neural network priors, and probabilistic graphical models.
