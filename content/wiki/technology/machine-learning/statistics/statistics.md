# Statistics

<p class="at-lead">
Statistics is the mathematical discipline underpinning all of data science and machine learning. It provides the language and tools to describe data, model uncertainty, test hypotheses, and make inferences from samples.
</p>

<span class="at-stat">descriptive</span> &nbsp;·&nbsp; <span class="at-stat">inferential</span> &nbsp;·&nbsp; <span class="at-stat">probability theory</span> &nbsp;·&nbsp; <span class="at-mark">every ML algorithm rests on statistical foundations</span>

<span class="at-kicker">Core Areas</span>

## Core areas

| Area | Purpose | Key Concepts |
| --- | --- | --- |
| **Descriptive statistics** | Summarise observed data | Mean, variance, std dev, correlation, covariance |
| **Probability theory** | Model random phenomena | Distributions, random variables, expected value, CDF/PDF |
| **Inferential statistics** | Draw conclusions from samples | Hypothesis testing, confidence intervals, p-values |
| **Information theory** | Measure uncertainty | Entropy, cross-entropy, KL divergence |
| **Simulation** | Approximate intractable problems | Monte Carlo methods, Gibbs sampling |

> [!tip] Why statistics matters for ML
> Every machine learning algorithm — from linear regression to deep neural networks — rests on statistical foundations. Understanding these foundations helps you diagnose model failures, design better experiments, and interpret results correctly.
