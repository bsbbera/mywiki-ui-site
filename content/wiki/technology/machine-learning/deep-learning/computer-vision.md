# Computer Vision

<p class="at-lead">
Computer Vision is the field of artificial intelligence that enables machines to derive meaningful information from digital images, videos, and other visual inputs. It powers applications from medical imaging and autonomous driving to facial recognition and quality inspection.
</p>

## Overview

Classical computer vision relied on hand-crafted features (SIFT, HOG, edge detection) and statistical methods. Modern CV is dominated by deep learning — especially **convolutional neural networks (CNNs)** — which automatically learn hierarchical visual representations directly from raw pixels.

Key tasks include image classification, object detection, semantic segmentation, instance segmentation, image generation, optical character recognition (OCR), and video analysis. Transfer learning via pretrained models (ImageNet, CLIP) has dramatically reduced the data and compute needed for new tasks.
