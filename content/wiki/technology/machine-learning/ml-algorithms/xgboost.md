# XGBoost

<p class="at-lead">
XGBoost (Extreme Gradient Boosting) is an optimised, distributed gradient boosting library designed for speed and performance. It dominates structured data competitions and production pipelines by combining tree ensemble power with advanced regularisation, missing value handling, and efficient parallel computation.
</p>

## Overview

XGBoost builds trees sequentially, with each new tree correcting errors made by previous ones. It adds L1 and L2 regularisation, supports custom objective functions, handles sparse data natively, and scales across clusters. Its ability to deliver state-of-the-art results with minimal tuning has made it the default choice for tabular classification and regression problems in finance, healthcare, and e-commerce.
