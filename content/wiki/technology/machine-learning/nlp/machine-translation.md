# Machine Translation

<p class="at-lead">
Machine Translation is the task of automatically converting text from one language to another while preserving meaning, style, and grammatical correctness. Neural Machine Translation (NMT) using encoder-decoder architectures and Transformers now powers Google Translate, DeepL, and virtually every modern translation system.
</p>

## Overview

Modern MT systems use sequence-to-sequence models with attention or pure Transformer architectures to learn mappings between languages from parallel corpora. The field has evolved from rule-based and statistical phrase-based systems to end-to-end neural approaches that achieve near-human quality on high-resource language pairs and continue to improve for low-resource and domain-specific settings.
