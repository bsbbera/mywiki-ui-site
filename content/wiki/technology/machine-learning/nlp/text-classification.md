# Text Classification

<p class="at-lead">
Text Classification is the task of assigning predefined categories to textual documents. It powers spam filtering, sentiment analysis, topic tagging, intent recognition, and content moderation — making it one of the most widely deployed NLP applications in industry.
</p>

## Overview

Modern text classification pipelines range from classical TF-IDF + logistic regression or Naive Bayes to deep learning approaches using CNNs, RNNs, and pre-trained Transformers fine-tuned for specific domains. The choice depends on dataset size, latency requirements, and interpretability needs, with Transformer-based models now dominating high-accuracy benchmarks.
