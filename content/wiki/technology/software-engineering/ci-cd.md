# CI/CD

<p class="at-lead">
CI/CD (Continuous Integration / Continuous Delivery or Deployment) is the practice of automating the build, test, and deployment of software. It enables teams to deliver code changes more frequently and reliably, reducing the risk and effort associated with releasing new features and fixes.
</p>

## Overview

Continuous Integration ensures that code changes are automatically built and tested against a shared repository, catching integration errors early. Continuous Delivery extends this by keeping code in a deployable state, while Continuous Deployment automatically releases passing builds to production. Tools like Jenkins, GitHub Actions, GitLab CI, and Cloud Build orchestrate these pipelines, enabling fast feedback loops and reliable software delivery.
