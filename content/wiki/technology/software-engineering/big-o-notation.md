# Big-O Notation

<p class="at-lead">
Big-O Notation describes the upper bound of an algorithm's growth rate as its input size increases. It provides a machine-independent way to reason about scalability, compare algorithms, and communicate performance characteristics across teams and languages.
</p>

## Overview

Common classes include O(1) constant time, O(log n) logarithmic, O(n) linear, O(n log n) linearithmic, O(n²) quadratic, and O(2ⁿ) exponential. Understanding Big-O is essential for choosing data structures, designing algorithms, analysing database query plans, and diagnosing performance bottlenecks in production systems.
