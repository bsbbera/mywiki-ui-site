# Site Reliability Engineering (SRE)

<p class="at-lead">
Site Reliability Engineering (SRE) is a discipline that applies software engineering principles to operations and infrastructure problems. It seeks to create ultra-scalable and reliable software systems through automation, monitoring, and error budget-driven release management.
</p>

## Overview

SRE practices include defining Service Level Objectives (SLOs) and Service Level Indicators (SLIs), managing error budgets that balance reliability against velocity, and eliminating toil through automation. SRE teams write code to manage infrastructure, build self-healing systems, and design for graceful degradation. The discipline has been codified by Google and adopted by organisations worldwide as the operational counterpart to DevOps culture.
