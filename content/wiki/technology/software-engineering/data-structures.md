# Data Structures

<p class="at-lead">
Data Structures are specialised formats for organising, storing, and accessing data efficiently. The choice of data structure directly impacts algorithm performance, memory usage, and code maintainability — making it a foundational skill in software engineering and systems design.
</p>

## Overview

Arrays, linked lists, stacks, queues, hash tables, trees, heaps, and graphs each optimise for different access patterns: random access, sequential traversal, LIFO/FIFO ordering, key-value lookup, hierarchical relationships, or network traversal. Understanding trade-offs in time and space complexity enables informed decisions when designing databases, caches, file systems, and distributed data pipelines.
