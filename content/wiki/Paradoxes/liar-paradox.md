# Liar Paradox

<p class="at-lead">
"This sentence is false." If it is true, then it is false; if it is false, then it is true. The canonical self-referential paradox undermines the assumption that every declarative sentence is either true or false, and has shaped logic, mathematics, and philosophy for millennia.
</p>

## Overview

The liar paradox is the most famous of all self-referential contradictions. Alfred Tarski's resolution proposes a hierarchy of languages: no language can contain its own truth predicate. The liar sentence is undefined because it attempts to assert truth about itself within the same language level.
