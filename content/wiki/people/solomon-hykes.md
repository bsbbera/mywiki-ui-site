> # Solomon Hykes

French-raised American entrepreneur and the original creator of **Docker**, the platform that made Linux containers mainstream and became the de-facto standard for application packaging and deployment. Hykes founded **dotCloud** (a PaaS competing with Heroku) in Paris in 2008 and open-sourced its internal container tooling in March 2013 under the name Docker — a release that changed the trajectory of software infrastructure.

Docker was built on top of Linux kernel features (namespaces, cgroups, union file systems) that had existed for years but were inaccessible to most developers. Hykes' contribution was the **user-friendly abstraction** — a simple CLI and image format — that made containers approachable. Within months Docker became one of the fastest-growing open-source projects in history.

After leaving Docker Inc in 2018, Hykes founded **Dagger**, a programmable CI/CD engine that runs pipelines in containers, continuing his focus on developer experience and portability.

## Key contributions

- **Docker** (2013): open-sourced the container format and toolchain that standardized application packaging
- **Docker Hub**: established the container registry ecosystem
- **Dagger** (2022): next-generation portable CI/CD engine built on Docker and WebAssembly
- Keynote speaker at DockerCon and contributor to OCI (Open Container Initiative) standards

## Interesting facts

- Docker was originally an internal side project at dotCloud; the open-source release was almost an afterthought that turned into a company-defining product
- Docker grew from 0 to 100k+ GitHub stars within 18 months of open-sourcing
- The Docker whale logo ("Moby Dick") has become one of the most recognizable icons in modern infrastructure
